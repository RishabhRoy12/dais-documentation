## 1. Purpose

Shows whether and where AI models **cite** the brand's website (and competitor domains) as a source when answering the brand's tracked prompts. It has:
1. An AI-written insight and recommended actions.
2. A line chart of **citation counts per source domain** over time (brand vs competitors).
3. A **prompt-by-date grid** showing, for every tracked prompt on every scan date, whether the brand's domain was cited (✓) or not (✗), with the cited URLs available on expand.

## 3. Section details

### 3.1 AI insight line
- Sparkle icon, one sentence, **BETA** pill.
- Pattern: "{Brand} has a {n}% citation rate across all {n} tracked prompts in ChatGPT as of {D(th) Month YYYY}, resulting in a {n}% explicit absence rate."
- Regenerated by an AI service on every load, so wording varies.

### 3.2 RECOMMENDED ACTIONS
Small uppercase label with a **BETA** pill, then a list of cards (3 seen; the number can vary).

| Part | Details |
|---|---|
| Left icon | Shield (RISK), eye (VISIBILITY), trend-up arrow (GROWTH) |
| Category badge | **RISK** (red) · **VISIBILITY** (neutral) · **GROWTH** (green) |
| Priority badge | **HIGH** (red) · **MEDIUM** (neutral); LOW would follow the same pattern but was not shown |
| Title | Bold one-line action, e.g. "Address {n}% citation rate across all {n} tracked ChatGPT prompts" |
| Description | Grey sentence with the numbers behind it (citations, explicit absences, week-over-week delta) |
| Recommendation | Teal text beginning with an arrow: "→ {recommended step}" |

Cards are read-only. Observed themes: zero citation rate; targeting specific prompt groups with no citations; establishing presence for prompt topics where the brand is missing.

### 3.3 Brand's Citations in AI Indexed Sources – {ChatGPT | Gemini}
Title in teal with an **ⓘ** icon; the model name follows the toggle. **ⓘ tooltip:** "Line chart showing your brand's citation frequency across AI-indexed sources compared to competitors."

| Element | Type | Details |
|---|---|---|
| **Domain filter** | Pill button "{n} of {total} brands" (default: all, e.g. "10 of 10 brands") | Opens a panel with **Select All** and **Clear** and a scrollable list of source **domains** (e.g. `{your-domain}`, `{competitor-domain}`). Click a row to select or deselect. **Clear** leaves one domain selected ("1 of {total} brands"); **Select All** restores all |
| **Date range** | Dropdown pill, default **Last 7 days** | Options: **Last 7 days** · **Last 14 days** · **Last 30 days** · **All time** |
| **Model toggle** | Two tabs **ChatGPT** (default, active = teal) · **Gemini** | Title becomes "… - Gemini" and the lines are reloaded for that model |
| **Chart** | Smooth multi-line chart, one line with point markers per selected domain | X: dates (`Mon D`) with axis title **Date**. Y: citation count (integers, 0 to rounded max) with axis title **Value** |
| **Legend** | Row above the chart: colour swatch + domain name; a **›** arrow at the right pages to more entries when they do not fit | Clicking an entry hides or shows that domain's line |
| **Hover** | Tooltip with the date and `{domain} : {n}` for every selected domain | |

### 3.4 Brand Domain Citations
Title with an **ⓘ** icon. **ⓘ tooltip:** "Tracks whether your domain is cited in AI-generated responses for each tracked prompt over time."

| Element | Type | Details |
|---|---|---|
| **Model toggle** | Tabs **ChatGPT** (default) · **Gemini** | Switches the grid between the two models. Independent of the chart's toggle |
| **Key** | Top-right: teal circle with ✓ labelled **Check**, teal circle with ✗ labelled **Cross** | Explains the cell icons |

**Grid columns**
| Column | Description |
|---|---|
| **Prompts** | Numbered tracked prompt (`1.` text …). Pinned to the left. Rows that have at least one citation show a **›** chevron before the number |
| **{D(th) Month YYYY}** (one column per scan date) | Scan dates, newest first, in ordinal long form, e.g. `{7th November 2026}`. Weekly in general, with some extra dates where extra scans happened (29 date columns in the sampled brand) |

**Cell values**
| Icon | Meaning |
|---|---|
| ✓ (check) | The brand's domain was cited in the model's answer to that prompt on that date |
| ✗ (red cross) | Not cited |

**Row expansion**
- Clicking a row that has a chevron expands a panel directly under it (the chevron points down).
- The panel lists, for each date on which the prompt was cited, the **date** (teal, e.g. `{12th September 2026}`) followed by the cited **URLs** (each with an external-link icon). Links open in a **new tab** (`target="_blank"`, `rel="noopener noreferrer"`).
- Rows with no citation have no chevron and cannot be expanded. The chevron points down when open, and clicking the row a second time **collapses** it again (the URL list disappears).

**Table behaviour**
- Header row is solid teal; it and the first column stay pinned while scrolling.
- The grid box is 500 px high with vertical scroll and horizontal scroll (30 columns).
- Cells have no hover tooltip; columns are not sortable; no search box, pagination or export.

## 5. Data sources and API calls

| Data block | Call | Input |
|---|---|---|
| Insight line and RECOMMENDED ACTIONS | `POST generate-page-insights` | `{ "page": "CitationOverview", "brand": "{Brand}", "source": "analytics_citations / analytics_citations_model", "signals": { "total_prompts_tracked": {n}, "latest_scan_date": "{date}", "previous_scan_date": "{date}", "latest_citations": {n}, … } }` |
| Brand grid (prompts × dates, cited URLs) | `POST fetch-citation-data` | Brand context |
| Cited source lists | `POST fetch-sources-data` | Called without dates, and with `{ "startDate": "{YYYY-MM-DD}", "endDate": "{YYYY-MM-DD}" }` for the chart range |
| Chart series (domain, model, date, mentions) | `GET citation_graph_data` (select `date_column`, `model`, `source_domain`, `mentions`; filter `brand_name ilike {Brand}`) | Re-requested on range and model changes |
| Brand lookup | `GET brands` (select `name`, `username_api`, filter by brand name) | Brand name |
| Usage tracking | `POST user_page_sessions` | `page_path: "/analytics/citations"`, `user_id` |

Shell calls (roles, subscription, notifications) are listed in [00-global-layout.md](00-global-layout.md) section 5.

## 6. Behaviour rules

- **Brand scoped:** all data is for the brand selected in the top bar.
- **Two model toggles:** the chart toggle and the grid toggle do not affect each other, and neither affects the insight text (which reports on ChatGPT, per its wording).
- **Citation rate** in the insight = prompts cited ÷ tracked prompts on the latest scan; **explicit absence rate** = prompts not cited ÷ tracked prompts.
- **Domain filter:** **Clear** keeps one domain selected, so the chart is never empty.
- **Expansion:** a row can be expanded only if the brand's domain was cited for that prompt on at least one date shown in the grid.
- **Generated content:** the insight line and action cards come from `generate-page-insights`; wording, number of cards, categories and priorities can differ between loads.
