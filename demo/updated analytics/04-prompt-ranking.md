## 1. Purpose

Shows where a brand appears when AI models (ChatGPT and Gemini) answer the brand's **tracked prompts**. It has three parts:
1. Two headline **visibility %** cards (one per AI model).
2. AI-written **insight and recommended actions** based on the latest scan.
3. A **week-by-week rank grid**: one row per tracked prompt, one column per weekly scan date, each cell showing the brand's rank position in that model's answer.

## 3. Section details

### 3.1 Current AI Visibility & Readiness
Section title with an **ⓘ** icon. **ⓘ tooltip:** "Snapshot of your brand's current readiness and visibility scores across AI search platforms."

Two equal cards side by side (left-aligned in the content area, each about a third of the page width). Each card has a caption with an ⓘ icon and a large teal value.

| Card | Value format | ⓘ tooltip text |
|---|---|---|
| **Gemini Visibility %** | `{n.nn}%` (two decimals, e.g. `0.00%`) | "Your brand's visibility percentage specifically within Gemini-generated responses." |
| **ChatGPT Visibility %** | `{n.nn}%` | "Your brand's visibility percentage specifically within ChatGPT-generated responses." |

Both cards always show; they do **not** change when the model toggle in AI Rankings is switched.

### 3.2 AI insight line
- Sparkle icon, one sentence, and a **BETA** pill.
- Generated text. It follows this pattern: "{Brand} has {n}% ranked coverage with {a} of {b} tracked prompts ranking and {n}% ChatGPT visibility as of {DD-Mon-YYYY}."
- The wording is **regenerated by an AI service**, so the same data can produce differently worded sentences on each load.

### 3.3 RECOMMENDED ACTIONS
Small uppercase label with a **BETA** pill, followed by a vertical list of cards (2 shown for the sampled brand; the number depends on the insight response).

**Card structure**
| Part | Details |
|---|---|
| Left icon | Shield icon for a RISK card, eye icon for a VISIBILITY card |
| Category badge | Small uppercase text: **RISK** (red) or **VISIBILITY** (neutral). These are the category values seen |
| Priority badge | **HIGH** (red) or **MEDIUM** (neutral); a LOW priority would follow the same pattern but was not shown |
| Title | Bold one-line action headline, e.g. "Resolve zero ranked prompt coverage across {n} tracked prompts" |
| Description | Grey sentence explaining the data behind the action |
| Recommendation | Teal text starting with an arrow: "→ {recommended step}" |

Cards are read-only (no buttons, no links, no dismiss). Content is AI-generated per load; titles and sentences vary between loads for the same data. Observed example themes: zero ranked prompt coverage; baseline presence in ChatGPT; "uncollected Gemini and Perplexity visibility metrics" (when those models return no values).

### 3.4 AI Rankings
Title **"AI Rankings"** with an ⓘ icon. **ⓘ tooltip:** "Weekly ranking positions of your brand across targeted AI prompts for each model."

| Element | Type | Details |
|---|---|---|
| Prompt count | Text, right-aligned on the title row | "{n} prompts": number of tracked prompts for the brand (rows in the grid) |
| **Model toggle** | Two tab buttons in a rounded track: **Gemini** · **ChatGPT** | **ChatGPT is active by default** (filled teal). Switching changes the rank values in the grid only |

**Rank grid (table)**
| Column | Description |
|---|---|
| **#** | Row number: `1.`, `2.` … Pinned to the left when scrolling horizontally |
| **Prompts** | Full text of the tracked prompt, wrapping to two lines when long. Pinned to the left |
| **{DD-Mon-YYYY} (one column per weekly scan)** | Weekly scan dates, newest first, 7-day step (26 weeks in the sampled brand). Each header has a small chevron; clicking opens a sort menu |

**Cell values**
| Value | Meaning |
|---|---|
| Number (`1`, `2`, `5`, …) | Rank position of the brand in the model's answer for that prompt on that date (1 is best). Plain centred text, no colour coding |
| **-** | The brand was not ranked for that prompt on that date |

**Column sort menu** (opens on clicking any date header)
| Option | Result |
|---|---|
| Sort Ascending (1→10) | Orders rows by that date's rank, best first; unranked rows (-) go to the bottom |
| Sort Descending (10→1) | Orders rows by that date's rank, worst first; unranked rows (-) stay at the bottom |

After sorting, the header shows a down-arrow icon. The `#` numbers are reassigned from top to bottom after sorting? **No**: row numbers move with the rows, so sorted views show the original numbers in a different order. Sorting is per column and one column at a time.

**Table behaviour**
- Header row is solid teal with bold text and stays visible while the body scrolls.
- Body scrolls **vertically** inside a box of max height 500 px and **horizontally** because the table is much wider than the card (28 columns).
- Rows are separated by thin lines; rows are not clickable and cells have no hover tooltip.
- There is no search box, no pagination, no export, and no date filter on this page; all weekly dates are always shown.

## 5. Data sources and API calls

| Data block | Call | Input / source |
|---|---|---|
| Model availability | `GET brand_model_config` (select `search_gpt`, `perplexity`, `gemini`, `ai_overview` …) | Which AI models are configured for the brand |
| Tracked prompt list ("{n} prompts", prompt text) | `GET prompts_brandwise` (select `prompts`, `brand`) | `brand in ({Brand})` |
| Prompt-selection permission | `POST rpc/get_prompt_selection_access` | `{ "_brand_name": "{Brand}" }` |
| Rank grid values | `GET weekly_prompt_ranking` (select `model`, `date`, `ranking`) | `brand_name in ({Brand})` |
| Visibility % cards | `POST fetch-prompt-visibility` | Brand context (empty body; brand taken from session) |
| Insight line and RECOMMENDED ACTIONS | `POST generate-page-insights` | `{ "page": "PromptRanking", "brand": "{Brand}", "source": "analytics_prompt_rankings / weekly_prompt_ranking / monthly_percentage", "signals": { latest scan figures … } }` |
| Usage tracking | `POST user_page_sessions` | `page_path: "/analytics/prompt-ranking"`, `page_label: "Prompt Ranking"`, `user_id` |

Shell calls (roles, subscription, notifications) are listed in [00-global-layout.md](00-global-layout.md) section 5.

## 6. Behaviour rules

- **Brand scoped:** all data is for the brand selected in the top bar.
- **Model toggle:** filters the grid by the `model` field of `weekly_prompt_ranking`; the visibility cards and generated text are independent of it.
- **Rank semantics:** value is a position in the model's answer; blank (**-**) = not ranked. "Ranked coverage" in the insight text = ranked prompts ÷ tracked prompts for the latest scan date.
- **Latest scan date:** the newest column in the grid (insight text quotes it, e.g. "as of {DD-Mon-YYYY}").
- **Generated content:** the insight line and action cards come from `generate-page-insights` and are not stored text; wording, number of cards, categories and priorities can differ between loads.
- **Sorting:** client-side, one date column at a time, unranked rows always last.
- **Missing model data:** if a model returns no values (for example Gemini or Perplexity), its visibility shows `0.00%` and an action card may call out the uncollected metric.
