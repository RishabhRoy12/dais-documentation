## 1. Purpose

Shows how many of the brand's **tracked keywords** rank in the search results at each position tier (Top 5, 10, 20, 50, 100), with AI-written insight and recommended actions, plus a **week-by-week table** of the rank of every tracked keyword.

## 3. Section details

### 3.1 Scan-date selector (top of page)
| Element | Details |
|---|---|
| Control | Button with calendar icon, selected date text and chevron. Default: the **latest scan date** in the long format `{D Month YYYY}` |
| Menu | Plain list of every available weekly scan date, newest first (one per week, 9 in the sampled brand). Single choice |
| Effect | Changes the **five tier cards** (value and the "as of {date}" line). It does not change the insight line, the action cards or the table |

### 3.2 Tier cards
Five equal cards in one row. Each card: round icon on top, large teal number, caption with an **ⓘ** icon, a thin divider, then "as of {D Month YYYY}".

| Card | Icon | Caption | ⓘ tooltip text |
|---|---|---|---|
| 1 | Trophy | Keywords in Top 5 | "Number of tracked keywords ranking in positions 1-5 on search engines." |
| 2 | Trend-up arrow | Keywords in Top 10 | "Number of tracked keywords ranking in positions 1-10 on search engines." |
| 3 | Target | Keywords in Top 20 | "Number of tracked keywords ranking in positions 1-20 on search engines." |
| 4 | Bar chart | Keywords in Top 50 | "Number of tracked keywords ranking in positions 1-50 on search engines." |
| 5 | Award badge | Keywords in Top 100 | "Number of tracked keywords ranking in positions 1-100 on search engines." |

Values are **cumulative**: Top 5 ≤ Top 10 ≤ Top 20 ≤ Top 50 ≤ Top 100 ≤ total tracked keywords.

### 3.3 AI insight line
- Sparkle icon, one sentence, **BETA** pill.
- Pattern: "{Brand} has only {a} of {b} tracked keywords in the Top 100 and zero in the Top 5, with no ranking movement between {previous date} and {latest date}."
- Always compares the **latest scan against the previous scan** (not the date chosen in 3.1). Wording is regenerated by an AI service on each load, so the same data can produce different sentences.

### 3.4 RECOMMENDED ACTIONS
Small uppercase label with a **BETA** pill, then a vertical list of cards (2 or 3 seen; the number and wording vary per load).

| Part | Details |
|---|---|
| Left icon | Eye (VISIBILITY), trend-up arrow (GROWTH), shield (RISK) |
| Category badge | **VISIBILITY** (neutral) · **GROWTH** (green) · **RISK** (red) |
| Priority badge | **HIGH** (red) · **MEDIUM** (neutral); a LOW priority would follow the same pattern but was not shown |
| Title | Bold one-line action, e.g. "Target indexation for {n} tracked keywords missing from Top 100" |
| Description | Grey sentence explaining the data behind the action |
| Recommendation | Teal text starting with an arrow: "→ {recommended step}" |

Cards are read-only (no buttons or links). Observed themes: keywords missing from the Top 100; moving Top 10 keywords into the Top 5; ranking stagnation (0 improved, 0 dropped keywords).

### 3.5 Keyword Performance Week Wise
Title with an **ⓘ** icon. **ⓘ tooltip:** "Weekly ranking positions for all tracked keywords, sortable by date column."

| Element | Type | Details |
|---|---|---|
| **Date multi-select** | Button with calendar icon, label **"{n} of {total} dates"** (default all selected) | Menu: **Select All** · **Clear** · one checkbox row per scan date (`{D Month YYYY}`, newest first). The table shows only checked dates. **Clear** keeps the latest date selected (label becomes "1 of {total} dates") |
| Table | Rank grid | See below |

**Table columns**
| Column | Description |
|---|---|
| **Sr. No** | Row number `1.`, `2.` … Pinned left |
| **Keywords** | The tracked keyword text, wrapping over up to 3 lines. Pinned left |
| **{D Month YYYY}** (one per selected date) | Rank position of the keyword on that scan, newest first. Each header has a chevron that opens a sort menu |

**Cell values**
| Value | Meaning |
|---|---|
| Number (`6`, `22`, …) | Rank position of the brand's page for the keyword on that scan date (lower is better). Plain centred text, no colour coding |
| **-** | Keyword not ranking (outside the tracked range) on that date |

**Sorting**
| Menu option | Result |
|---|---|
| Ascending (1 → 100) | Best rank first |
| Descending (100 → 1) | Worst ranked number first |

- Unranked keywords (**-**) always stay at the bottom, for both directions.
- Default state: sorted **ascending by the latest date**; that header shows **▲**. Choosing descending shows **▼** on that column; the arrow is shown only on the sorted column.
- Sorting is done in the browser, one column at a time.

**Table behaviour**
- Header row is solid teal and stays visible while the body scrolls.
- Table box has a fixed height of 500 px and scrolls vertically; it also scrolls horizontally when many dates are selected. First two columns stay pinned.
- Rows are separated by thin lines, are not clickable and have no hover tooltip.
- No search box, pagination or export.

## 5. Data sources and API calls

| Data block | Call | Input / source |
|---|---|---|
| Tier cards, scan-date list, week-wise table | `POST fetch-keywords-ranking` | Empty body; brand taken from the session |
| Keyword-selection permission | `POST rpc/get_keyword_selection_access` | `{ "_brand_name": "{Brand}" }` |
| Insight line and RECOMMENDED ACTIONS | `POST generate-page-insights` | `{ "page": "KeywordRanking", "brand": "{Brand}", "source": "analytics_keywords (keyword ranking summary)", "signals": { "total_tracked_keywords": {n}, "latest_date": "{date}", "previous_date": "{date}", … } }` |

Shell calls (roles, subscription, notifications) are listed in [00-global-layout.md](00-global-layout.md) section 5. Changing the scan date in 3.1 makes a new `generate-page-insights` call, although the displayed insight text is for the latest-vs-previous scans.

## 6. Behaviour rules

- **Brand scoped:** all data is for the brand selected in the top bar.
- **Tier counting:** a keyword counts toward a tier when its rank on the chosen scan date is within positions 1 to the tier limit; unranked keywords count in no tier.
- **Total tracked keywords:** the number of rows in the table (`{n}`), used in the insight and action texts ("{a} of {b}").
- **Scan cadence:** weekly; dates come from the ranking data, not from a calendar.
- **Date control scope:** the top selector affects the five cards only; the "{n} of {total} dates" menu affects the table columns only; the insight line and action cards always describe the latest vs previous scans.
- **Generated content:** the insight line and action cards come from `generate-page-insights`; wording, number of cards, categories and priorities can differ between loads.
- **Sorting:** client-side, unranked rows always last.
